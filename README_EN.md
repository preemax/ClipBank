# ClipBank

**ClipBank** is a fast and customizable clipboard manager for Windows, designed for managing text, images, file paths, and multiple independent clipboard banks.

> Current release: **v1.1.38**

## Download

**[Download ClipBank-Setup-v1.1.38.exe](https://github.com/preemax/ClipBank/releases/download/v1.1.38/ClipBank-Setup-v1.1.38.exe)**

Or visit the **[latest release](https://github.com/preemax/ClipBank/releases/latest)**.

## Highlights

- Multiple independent clipboard banks
- Recent clipboard history with configurable size from 10 to 500 items
- Text, image, and file-path support
- System tray popup with page-based navigation
- Hover preview for text and images
- Global hotkeys
- Quick Paste mode
- Favorites / pinned lists
- Most-used items
- Dark and light themes
- Persian text and Jalali calendar support
- Image preview with zoom and pan
- Windows installer with Upgrade / Repair / Modify / Uninstall

## Requirements

- Windows 10 or Windows 11
- x64

Current releases are self-contained and normally do not require a separate .NET Runtime installation.
